# 单轴拉伸计算内核说明

本文件说明首版的实际计算方法，供后续 Python 与有限元教学使用。结果由网格平衡、材料更新和损伤演化得到，没有预设应力—应变曲线，也没有按目标形状修改颈部。

## 几何、单位与边界

- 坐标列依次为轴向 `z`、径向 `r`；长度 mm，应力 MPa，力 N。
- 圆棒标距段采用四节点轴对称单元，每个单元使用 2×2 高斯积分；积分权重包含完整的 `2πR`，因此计算的是整根圆棒的反力。
- 左端轴向固定，右端所有节点施加相同轴向位移，轴线上径向位移为零。两端径向自由，尚未模拟夹具接触及试样过渡圆角。
- 中部半径有明确可输入的小幅高斯形初始缺陷，用于选择颈缩位置。该缺陷只改变初始网格；随后的颈缩由计算产生。

## 大变形和材料更新

总变形梯度包括轴向—径向 2×2 子矩阵与环向伸长 `r/R`。以相邻时刻的变形梯度更新弹性左 Cauchy–Green 张量，在其主方向内进行对数弹性应变的 J2 返回映射。该更新能处理大转动和大塑性变形，不是将小应变公式直接用于大伸长。

流动应力采用 Voce 规律：

`Y(p) = σy + Q [1 − exp(−b p)]`

这里 `p` 为累积等效塑性应变；返回映射采用 Kirchhoff 应力。体积弹性部分采用单元平均对数体积应变，以缓解近似不可压缩塑性下的体积锁死。损伤后平均体积应变也按剩余承载能力加权，完全失效的积分点不再产生压力耦合。

## 损伤与断裂

达到输入的等效塑性应变阈值 `p0` 后，使用轴向初始单元长度 `h` 定义塑性位移 `u = h(p − p0)`。在损伤起始流动应力 `Y0` 下，终止位移为 `uf = 2Gf/Y0`，其中断裂能 `Gf` 的单位为 **N/mm**，即单位断裂面积耗散的能量。

通过逐步降低完整应力张量，使后续有效牵引随塑性位移近似线性软化。积分点完全失效后，其应力为零；一个单元全部积分点失效后，该单元不再传力。只有出现完全失效的横向单元带，才判定试样断开。

这是简化的延性损伤模型，未加入应力三轴度相关的断裂应变、孔洞生长、裂纹面接触或杯锥断口细节。特征长度能减轻软化的网格依赖，不能保证断裂应变、颈部尺寸和断口形貌已经网格收敛。模型参数应视为教学参数。

## 加载与结果采样

采用显式速度 Verlet 积分与数值质量，时间为**伪时间**，不是材料的实际拉伸速率。全程采用五次多项式平滑慢加载，约经历 800 个初始弹性波轴向穿越时间；不在颈缩过程中突然暂停、重启边界速度。

检测到真实断开后停止增加位移，用数值阻尼松弛释放的弹性波。曲线最后一个点取该位移下实际求得的卸载状态，不人为裁剪或置零反力。断裂瞬态的左右反力保存在 `diagnostics.fracture_transient` 中。

- 工程应力：**加载端轴向反力 / 初始名义截面积**。
- 工程应变：**端部相对伸长 / 初始标距**。
- 云图：当前构形中的单元平均轴向 Cauchy 应力、等效塑性应变与损伤。
- 左右反力分别保存；双端平均值只作为附加数据，不替代加载端测量。
- 外功在每个显式步积分。动能及阻尼耗散仅统计自由自由度；与内功一起保存在能量诊断中。
- 最小半径仅统计仍连接有效单元的外表面节点，排除失效后不再属于可见试样的孤立节点。

## 已执行的独立检查

执行 `python -m tests.verify_solver`，结果保存到 `verification-output/solver_verification.json`。

1. 轴对称体积及集总质量与 `πR²L` 一致。
2. 小应变拉伸得到 `E ≈ 199970 MPa`、`ν ≈ 0.29998`，输入分别为 `200000 MPa` 和 `0.3`。
3. 均匀有限应变塑性与独立标量解比较：解析工程应力约 `477.934 MPa`，计算约 `477.928 MPa`。
4. 对已受力材料施加刚体转动，验证应力随转动客观变换。
5. 20×3 与 40×6 网格都在试样中部形成颈缩及实际断开。峰值应力分别约 `496.137 MPa`、`496.174 MPa`；断裂工程应变约 `29.65%`、`28.72%`。这只是两种网格的检查，不构成收敛证明。
6. 检查断裂后反力接近零、能量平衡、取消时保留最后有效帧。
