虚拟仿真实验室 使用说明
版本：2.1

一、解压与安装

1. 找到安装包：
   MechanicsVirtualLab-v2.1-Windows-x64-offline.zip

2. 右键点击安装包，选择“全部解压缩”，将全部文件解压到电脑上的一个文件夹。
   不要在压缩包内直接运行安装文件。

3. 打开解压后的文件夹，双击 install.cmd。
   选择安装父目录，程序会安装到其 TensileLab 子目录；取消选择则退出安装。
   等待出现“安装完成”提示，然后按任意键关闭安装窗口。

4. 双击桌面上的“力学虚拟实验室”快捷方式，即可打开程序。
   程序窗口的标题为“虚拟仿真实验室”。

说明：
本安装包为 Windows 64 位版本，已在 Windows 11 上验证。
程序自带运行环境和标准实验记录，安装、运行均不需要联网，也不需要另外安装 Python。
如果电脑上已经安装过旧版，请先关闭正在运行的实验室，再进行安装；安装后继续使用原有桌面快捷方式。

二、快速开始：播放标准实验

1. 在窗口上方选择实验：拉伸、压缩、扭转、弯曲、剪切或压杆失稳。
2. 在左侧选择材料 Fe 或 Al，以及圆形或矩形截面。
3. “尺寸方案”选择“标准试样（预计算）”。程序将载入相应标准记录。
4. 点击“播放”，即可同时观察试样变形、受力情况和实验曲线。
5. 试样下方可切换“写实示意 / 网格云图”。写实示意为同类实验共用动画，裂纹和褶皱不是计算预测；网格云图显示当前计算的变形和场值。

程序内置24份标准记录，可直接回放，无需等待重新计算。

三、修改试样尺寸并计算

1. 在“尺寸方案”中选择“手动尺寸”。
2. 输入初始长度 L：
   圆形截面还需输入直径 d；
   矩形截面还需输入宽度 b 和高度 h。
   所有尺寸单位均为毫米（mm）。
3. 拉伸、压缩实验可设置“最大工程应变”；其他加载设置可在“加载与计算设置”中调整。
4. 点击“开始计算”或“重新计算”。计算完成后即可播放和导出。

首次计算可能较慢，请等待进度提示。需要停止时，可点击“取消计算”。
修改参数后，只有重新计算才会得到新参数的结果；此前显示和导出的仍是上一份实验记录。
点击“恢复本实验标准参数”，可回到该实验的默认设置。

四、课堂常用操作

播放／暂停：连续播放或暂停实验过程。
单步：逐个加载步观察。
重置：回到当前实验记录的初始帧。
实验回放滑块：拖动到指定加载步。
播放速度：选择慢放、正常播放或快放。
显示网格：显示或隐藏试样网格。
场图选择：查看当前实验支持的应力、变形等结果。
变形显示／转角显示：调整显示放大倍数，方便观察；不会改变曲线和导出数值。
全屏 F11：切换全屏，适合课堂投影。
实验说明：查看当前实验的加载条件、计算模型和适用范围。

五、导出与再次打开实验

1. 点击“导出数据”，选择保存位置。
2. 程序会生成一个独立的实验结果文件夹，主要包括：
   CSV：实验曲线数据和最终场结果，可用 Excel 或 Python 读取；
   PNG：实验曲线图片；
   JSON：实验参数和计算状态；
   NPZ：完整实验记录，供以后回放；
   数据说明.txt：对应实验的数据含义与单位。
3. 如需再次查看，点击“打开记录”，选择导出的“完整实验记录.npz”。

回放过程中导出的内容为当前记录的完整加载历史，不只是画面所在的那一帧。

六、使用时需要了解

各实验的曲线不同：拉伸、压缩为工程应力—应变；扭转为扭矩—转角；弯曲为载荷—挠度；剪切为剪应力—剪应变；压杆失稳为轴压力—侧向挠度。

本程序用于课堂教学。Fe、Al 为教学代表参数。拉伸可展示局部变细和断裂，其中矩形试样采用杆单元近似；扭转、弯曲和剪切演示弹性阶段，压杆失稳展示临界前响应。具体说明可点击“实验说明”查看。

七、常见问题

没有找到 install.cmd：请确认已完整解压，并打开解压后的文件夹。
无法修改长度或截面尺寸：请先将“尺寸方案”改为“手动尺寸”。
修改尺寸后画面没有变化：请点击“开始计算”或“重新计算”。
变形不明显：可调大显示倍数，或拖动回放滑块到后面的加载步。
安装未完成：保留安装窗口中的错误信息；如果旧版程序仍在运行，先关闭它再重新安装。
